## [0.1.0] - 2026-04-13

### Added
- Semantic search using ONNX embeddings
- Code distillation for compact context
- DuckDB storage for indexed units
- AST-based parsing for precise symbol extraction
- CLI with `sync`, `search`, and `api` commands
